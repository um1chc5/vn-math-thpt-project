# Loại đề (exam-type YAML)

Folder này **cố ý trống**. Không có 15-phút / giữa kỳ / THPT QG sẵn.

Menu lựa chọn: [src/docs/onboarding.md](../../docs/onboarding.md) §2.

Khi thầy/cô chọn một loại, agent tạo `<slug>.yaml` ở đây. Generator: `--loai-de <slug>`.

Mọi loại đề đều có thể trộn nhiều dạng câu. Cấu trúc mặc định (nếu giáo viên muốn) nằm trong `sections`; xem [onboarding §2](../../docs/onboarding.md). Không suy ra cấu trúc từ tên loại đề.
